# fixtures/parsers/xlsx_dir — SOURCE

Fixtures for `parserXLSX_DIR` (Excel workbook variant of DIR). The parser is a thin
wrapper: `XLSX.read(bytes)` → `xlsx_to_csv(workbook)` → `parseCSV_DIR`. So these
fixtures mirror `csv_dir/` cell-for-cell; each reference equals its `csv_dir` sibling
except `name` (which echoes the `.xlsx` filename).

## Layout

- `real/` — real `.xlsx` files. Empty: deferred to a follow-up export run — see PR 3
  in [part-a-pr-plan.md](../../../../../.claude/development-roadmap/part-a-pr-plan.md).
- `synthetic/` — generated by [`scripts/generateXlsxFixtures.js`](../../../../../scripts/generateXlsxFixtures.js).
