# fixtures/parsers/xlsx_sites_latlon — SOURCE

Fixtures for `parserXLSX_SitesLatLon` (Excel workbook with site lat/lon). The parser
is a thin wrapper: `XLSX.read(bytes)` → `xlsx_to_csv(workbook)` → `parseCSV_SitesLatLon`.
So these fixtures mirror `csv_sites_latlon/` cell-for-cell; the output carries no
`name` field, so each reference is byte-identical to its `csv_sites_latlon` sibling.

## Layout

- `real/` — real `.xlsx` site-data files. Empty: deferred to a follow-up export run —
  see PR 3 in [part-a-pr-plan.md](../../../../../.claude/development-roadmap/part-a-pr-plan.md).
- `synthetic/` — generated by [`scripts/generateXlsxFixtures.js`](../../../../../scripts/generateXlsxFixtures.js).

## Real-file origins

_Deferred — populated by an export run in a follow-up PR (see PR 3 plan)._

## Synthetic-fixture matrix

| File | Sheets | Locks |
|------|--------|-------|
| `basic_sites.xlsx` | `data` | happy path: `label,lat,lon` header, three sites, absent `age`/`plate_id` → `null`, the `csv_sites_latlon` data through the XLSX read path. |
